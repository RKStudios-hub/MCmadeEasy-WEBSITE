# MCmadeEasy Website

Official website for **MCmadeEasy** — a smart and user-friendly **Minecraft server launcher** currently in development.

This repository contains the source code for the **MCmadeEasy promotional website**, which will showcase the launcher, its features, updates, and provide downloads once the project is released.

---

## 🚀 About MCmadeEasy

**MCmadeEasy** is designed to simplify the process of running and managing Minecraft servers.
The launcher aims to make server setup easier, faster, and more accessible for both beginners and experienced players.

Planned goals include:

* ⚡ Easy Minecraft server setup
* 🧩 Simple mod and plugin support
* 📦 Integrated tools for server management
* 🖥️ Clean and intuitive interface
* 🔄 Automatic updates and improvements

---

## 🌍 Website Purpose

The website will serve as the **official hub** for the project where users can:

* Learn about MCmadeEasy
* Explore upcoming features
* Download the launcher
* Stay updated with development progress
* Access documentation and guides
