Getting Started

MCmadeEasy is a modern Minecraft server management client that allows you to easily launch, configure, and manage your Minecraft servers. It features an intuitive GUI, AI-powered configuration, real-time console, automatic backups, and supports multiple server types.
Visit our download page and select your platform (Windows, macOS, or Linux). Download the installer or portable version, then run the executable. For Windows, you may need to click "Run anyway" if you get a security warning - this is harmless as the app is not code-signed.
MCmadeEasy requires:
• OS: Windows 10+, macOS 10.15+, or Linux
• RAM: 4GB minimum, 8GB recommended
• Storage: 500MB for installation
• Java: Version 21 or higher (included in installer for Windows)

Configuration

Click the "+" button in the dashboard, select your server type (Spigot, Paper, Fabric, or Vanilla), choose the Minecraft version, and configure the server settings. You can use the AI configuration feature to automatically optimize settings based on your intended player count and mods.
Yes! MCmadeEasy supports Fabric and Forge modloaders. When creating a server, select "Fabric" or "Forge" as the server type, then add your preferred mods. The AI configuration can help optimize server settings for modded gameplay.
Select your server from the dashboard, then click "Server Settings". Here you can modify server.properties, spigot.yml, paper.yml, and other configuration files through an intuitive interface. Changes require a server restart to take effect.

Troubleshooting

First, check the console for error messages. Common solutions include:
• Ensure Java 21 is installed and selected in settings
• Check if the port (default 25565) is already in use
• Verify server RAM allocation is not exceeding available memory
• Check if server files are corrupted - try reinstalling the server
MCmadeEasy requires Java 21. Download and install Temurin Java 21 LTS. After installation, go to Settings > Java and select the path to your Java installation (usually C:\Program Files\Eclipse Adoptium\jdk-21 on Windows).
Some antivirus programs may flag MCmadeEasy as a false positive. This is harmless and happens because the app is not code-signed (which costs $400+/year). Add MCmadeEasy to your antivirus exceptions or click "Run anyway" when prompted. We actively work with antivirus companies to resolve these issues.
Visit our GitHub Issues page and create a new issue. Include details like your operating system, MCmadeEasy version, steps to reproduce, and any error messages. For urgent issues, join our Discord server.
